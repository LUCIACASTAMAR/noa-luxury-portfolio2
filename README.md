# Noa Younes Regidor — Portfolio actualizado

Portfolio estático responsive para VS Code, GitHub y Vercel. Incluye selector desplegable de seis idiomas: English, Español, Italiano, Français, Deutsch y Nederlands. La selección se guarda en el navegador. No incorpora fotografías ni asistente de IA.

## Archivos
- `index.html`: estructura y selector de idiomas.
- `style.css`: diseño y adaptación móvil.
- `script.js`: traducciones y funcionamiento del selector.
- `vercel.json`: configuración de despliegue estático.

## Ejecutar localmente
Abre la carpeta en VS Code y utiliza Live Server, o abre `index.html` directamente en el navegador.

## Publicar en Vercel
Importa el repositorio de GitHub en Vercel. Selecciona **Other** como framework, deja vacío Build Command y usa `.` como Output Directory.

## Antes de publicar
Confirma las fechas de los másteres y añade el correo profesional correcto. La fecha del grado se ha tomado del perfil compartido; Erasmus+ se incluye como experiencia académica complementaria.
